# 🛒 Amazon Clone

A frontend **Amazon Clone** built using **HTML and CSS**.
This project recreates the look and feel of Amazon's shopping interface, including a navigation bar, search bar, shopping cart, product sections, product cards, recommendations, and a products listing page.

> 🚀 This project was created for learning and practicing frontend web development.

## 📸 Project Overview

The Amazon Clone contains:

* Amazon-style navigation bar
* Amazon logo and shopping cart section
* Product search interface
* Home page with multiple product sections
* Related products section
* Grocery products section
* Product recommendation cards
* Dedicated products page
* Product names and prices
* Sign-in / recommendation section
* Footer

The homepage contains sections such as **"Top picks for your home"**, **"Best Sellers in Grocery & Gourmet Foods"**, and **"Inspired by your browsing history"**.

## ✨ Features

### 🏠 Home Page

The homepage is designed to resemble Amazon's shopping homepage with:

* Header navigation
* Amazon logo
* Search bar
* Cart icon
* Promotional/product sections
* Horizontal product cards
* Personalized recommendations
* Sign-in section
* Footer

The product sections use horizontally scrollable card layouts to display multiple products.

### 🛍️ Products Page

A separate products page displays a collection of products including:

* Monitor
* Laptop
* Smartphone
* Tablet
* Headphones
* Smartwatch
* Grocery products

Each product contains an image, name, and price.

### 🎨 Amazon-Inspired UI

The project uses Amazon-inspired colors such as:

* Dark navigation bar
* Amazon orange/yellow search button
* White product cards
* Light gray page background

The styling uses CSS variables for the major background, secondary background, and Amazon accent color.

## 🛠️ Technologies Used

| Technology   | Purpose                        |
| ------------ | ------------------------------ |
| HTML5        | Structure of the website       |
| CSS3         | Styling and layout             |
| Google Fonts | Poppins typography             |
| SVG          | Shopping cart and search icons |

The project uses **Poppins** as its primary font and CSS variables for reusable colors.

## 📁 Project Structure

```text
Amazon-Clone/
│
├── index.html
├── style.css
├── products.html
├── products.css
└── README.md
```

### `index.html`

Contains the main Amazon-style homepage, including the navigation bar, product sections, recommendations, and footer.

### `style.css`

Contains the styling for the homepage, including:

* Header
* Search bar
* Cart
* Product sections
* Product cards
* Recommendation section
* Footer

### `products.html`

Contains the dedicated products listing page with multiple product cards and prices.

### `products.css`

Contains styling for the products page, including the product grid, product cards, images, names, and prices.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/asivasaipavan/Amazon-Clone.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd Amazon-Clone
```

### 3. Run the project

Simply open:

```text
index.html
```

in your browser.

You can also use **VS Code Live Server** for a better development experience.
